# Kultur & Art frontend demo

A framework-free HTML/CSS design foundation for the Kultur & Art Initiative e.V. website.

## Structure

```text
.
├── assets/
│   ├── brand/
│   └── reference/
├── css/
│   └── styles.css
├── docs/
│   └── reference-analysis.md
├── js/
│   └── main.js
└── index.html
```

No build step or dependencies are required. The current homepage includes the complete single-page section flow, responsive navigation, supplied hero video, and lightweight scroll interactions.

The global design tokens and reusable layout primitives live in `css/styles.css`. The reference analysis in `docs/reference-analysis.md` explains the layout observations and how they translate to Kultur & Art's visual language.
